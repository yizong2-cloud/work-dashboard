# Workboard 二次元视觉素材需求（交给绘图 AI）

## 目标

为一个面向 Leader 的个人工作进度看板制作统一角色插画。角色负责提供二次元气质，界面本身保持专业、干净、易读。

默认角色方向：**Q 版二次元技术助理少女**。她不是儿童，也不性感化；气质聪明、亲切、可靠，有轻微元气感。深棕色中长发、暖棕色眼睛、淡紫色连帽外套或简洁工装，配一个小型对勾发夹作为识别点。

如果最终决定换成男生、机器人或动物，只替换角色设定，其余构图和输出规范不变。

## 统一画风

- 日系 Q 版二次元，2.5–3 头身
- 干净而有变化的手绘线稿，避免机械矢量感
- 平涂为主，仅保留一层柔和阴影和少量高光
- 主色：淡紫、暖白；点缀：珊瑚粉、少量金黄
- 表情自然，动作清楚，在缩小到 160–240 px 时仍然易读
- 不要文字，不要 UI 面板，不要复杂背景，不要发光特效
- 每张都要透明背景 PNG，同时保留高分辨率源文件
- 所有图片必须是同一个角色、同一服装、同一线条和上色方式

## 第一步：先生成角色设定表

### 提示词

> 为个人工作进度看板设计一名统一的 Q 版二次元技术助理少女角色。成年女性气质，2.5–3 头身，深棕色中长发，暖棕色眼睛，淡紫色简洁连帽外套，暖白内搭，佩戴一个很小的对勾形发夹。聪明、亲切、可靠，略带元气感，但不过度幼态，不性感化。日系动画角色设计，干净但有自然变化的手绘线稿，平涂为主，一层柔和阴影，淡紫、暖白、珊瑚粉配色，少量金黄点缀。输出正面、四分之三侧面、侧面、背面、三种表情和完整配色板。纯白背景，角色设定表，不要 UI，不要文字水印，不要复杂道具。

设定表确认后，后面的每张图都必须以它为唯一角色参考。

## 第二步：首批 5 张透明插画

### 1. 总览页主视觉：正在汇报

> 使用已确认的同一角色和同一服装。Q 版二次元技术助理少女，半身到四分之三身，站在画面右侧，身体朝左，手持简洁文件夹，另一只手自然指向左侧内容区域，表情自信亲切，像在向 Leader 汇报工作。构图重心在右下，左侧和上方保留大量透明留白。干净手绘线稿，平涂，一层柔和阴影，透明背景 PNG，不要文字，不要 UI 面板，不要发光，不要复杂装饰。

### 2. 正在工作

> 使用已确认的同一角色和同一服装。角色坐在小桌前专注使用笔记本电脑，一只手敲键盘，旁边只有一个小记事本和一杯水，表情认真但轻松。紧凑轮廓，适合缩小成状态插画。透明背景 PNG，不要文字，不要 UI，不要复杂背景。

### 3. 出现阻塞

> 使用已确认的同一角色和同一服装。角色略微皱眉，双手举着一个简洁的珊瑚红色感叹号牌，旁边有一小段打结的数据线作为阻塞隐喻。焦急但不过度沮丧，轮廓清楚。透明背景 PNG，不要文字，不要 UI，不要警报灯和夸张特效。

### 4. 任务完成

> 使用已确认的同一角色和同一服装。角色开心但克制地举起一个绿色对勾牌，另一只手轻轻握拳庆祝，周围只允许 3–5 个很小的金色纸屑。透明背景 PNG，不要文字，不要 UI，不要大面积光效或烟花。

### 5. Leader 留言

> 使用已确认的同一角色和同一服装。角色从画面下方探出半身，双手捧着一个空白的圆角对话气泡，表情专注倾听。对话气泡必须完全空白，后续由网页承载真实留言内容。透明背景 PNG，不要文字，不要 UI，不要背景。

## 输出规格

- 角色设定表：至少 2400 × 1600 px
- 单张透明插画：至少 1600 × 1600 px，PNG-24，透明背景
- 构图四周保留 8% 安全边距，不裁头发、手、衣服或道具
- 另导出一份 WebP 透明背景版本
- 文件名：`mascot-hero`、`mascot-working`、`mascot-blocked`、`mascot-completed`、`mascot-comment`

## 统一负面要求

> 不要 3D，不要黏土质感，不要厚重渐变，不要玻璃拟态，不要霓虹，不要复杂背景，不要海报排版，不要 UI 截图，不要文字，不要水印，不要多个角色，不要改变服装，不要改变发色和瞳色，不要过度幼态，不要性感化，不要高饱和荧光色，不要过多星星、爱心、胶带或光晕。

## 暂时不要生成的东西

- 搜索、日历、评论、箭头等 16–24 px 功能图标：网页统一使用专业线性图标库
- 带文字的简报海报：文字会失真，也不能适配实时数据
- 大面积背景图：会降低任务信息可读性，并增加手机端负担
