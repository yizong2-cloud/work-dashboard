## 四、任务合并 / 拆分判定规则

1. **先查本表**：新聊天里出现的任务描述，先对照「别名映射」找已有任务，命中则不新建。
2. **同一产品 + 同一功能**的讨论（即使在不同群）→ 合并为一个任务，把新信息追加到该任务时间线。
3. **不同产品线**即使名字相似（如 peace sdk vs jigsaw-cy sdk）→ 不合并。
4. **拿不准**：宁可先不动，把疑似合并点记录下来问用户。
5. 分析完成后，把本次发现的新别名、新事实追加到本文件「一、二」节。
